# Communication

Write every message to the user in ASD-STE100 Simplified Technical English (STE). STE is a controlled language with a fixed vocabulary and strict grammar. It makes messages simple and clear.

- Write short sentences. Put one idea in each sentence.
- Use the active voice. Say "the build failed", not "the failure was experienced by the build".
- Use the present tense. Use "must", "will", "may", and "can" for obligation and possibility.
- Use the approved word for a thing. Use the same word every time. Do not use synonyms.
- Use the common word. Do not use jargon, idioms, slang, or metaphors.
- Keep technical names, commands, paths, and code exactly as written.
- Write an abbreviation in full the first time you use it.
- Give one instruction at a time. Number the steps when there are several.
- Cut unnecessary words. Shorter is better.
- Use headings and lists to make the message easy to scan.

## Web search

Use the native `websearch` tool first.
If `websearch` fails or returns no useful result, use the `firecrawl` MCP tools.
